# 记忆来源归属实验 · Lab 页面

Agent 记忆方向的本科入门实验：判断一条合并记忆该归给谁，再用一段 Python 比较「严格归属」与「多数归属」两种规则。

- 实验页面：`index.html`（自包含单页，无需构建、无外部依赖）
- 学生 starter 包：`memory_starter.zip`（原样分发，不解压、不改内容；包内含 `memory_provenance_lab.py`、`memory_store.json`、`truth.json`、`results.csv`、`README.md`、`experiment_record_template.md`）

页面内容与交互：六道来源判断题（能 / 不能 / 说不清，点击即出结果与解析，可重选）、两种规则对比、三张真实结果卡、第一次小任务卡（含邮件联系）、可选进阶（扩到 14 条与 70% 阈值）、实验边界、附录 A 预期输出表与附录 B 指标口径。

页面里的统计数字均来自 `memory_provenance_lab.py` 的实跑结果（严格模式攻击样本错误接受 0/5、多数模式 4/5 等），修改脚本后需同步更新页面数字与附录表。

素材来源：李晓玉（计算机工程与科学学院）的交付材料。
