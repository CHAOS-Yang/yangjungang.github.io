新手实验 · 不用模型和 API

记账助手把你的话和工具账单记在一起，这条记忆该归给谁？

你说过“我不吃香菜”，账单工具返回“上月餐饮支出 1180 元”。两句话合并到同一条记忆后，系统却想给它贴一个来源标签。大部分内容来自你，能不能把整条都归给你？先做六次判断，再用一段 Python 看看两种规则的区别。

Try It · 先玩一下

六段记忆，你来判断

锚点是每句话留下的来源短码，用对应来源的密钥重算能对上，才算有来源证据。先不用懂计算公式。

每题只问：现有证据是否足以把整条记忆归给它申报的来源？选项为“能 / 不能 / 说不清”。先选，再看解析。这里的判断采用严格证据标准。选择只保存在当前页面，刷新即清空，不收集任何个人信息。

第 1 题

三句话都能对上用户 U 的锚点，申报来源 U。

第 2 题

三句话都能对上账单工具 T 的锚点，申报来源 T。

第 3 题

两句命中 U，两句命中 T，锚点全部完好，申报来源只有 U。

第 4 题

三句命中 U，另有一句工具内容但锚点被删，申报来源 U。

第 5 题

三句内容还在，但全部没有锚点，申报来源 U。

第 6 题

三句命中 U，第四句换成了工具内容，却保留某句旧的用户内容锚点，申报来源 U。

做完后，你已经练习了三个动作：检查证据、比较申报、在证据不足时拒绝整体归属。

Two Rules · 两种规则究竟差在哪

严格模式与故意粗糙的多数模式

严格模式

要求现存句子全部命中，且命中来源集合与申报一致。

多数模式

只看命中最多的来源是否占全部现存句子至少 50%，达到就把整条归给它；平票时取字母序较大的来源，因此 U/T 平票取 U。这是故意粗糙的对照规则。

两种模式都会输出这些状态，但接受条件不同

状态含义
attributed规则接受了归属；是否正确还要比对真值
partial有来源命中，但不足以按该规则整体接受；仍可报告已识别来源
unknown一句来源也未命中

“错误归属”由评测端判断：系统已接受，但输出来源集合与真实来源集合不一致。它不是验证器额外输出的第四种状态。

为什么实验拆成两个文件

memory_store.json

提供记忆和虚构密钥。判定函数 verify_record() 读它，不读取 truth。

truth.json

存评测端真实来源集合及扰动前应有句数。只有评测函数 verify() 才用它打分。

Three Real Results · 先观察三个真实结果

同一个证据，两种规则给出不同结论

一句外来内容，多数模式仍接受

A2 有四句用户内容和一句工具内容，工具句锚点被删，申报 U。

严格：partial(U)      覆盖 0.80
多数：attributed(U)   覆盖 0.80

多数规则把 4/5 当作整体来源依据，输出与真实来源集合 U+T 不一致。

合法混合也会被归错

N3 有两句 U、两句 T，证据完整，申报 U+T。

严格：attributed(T+U)   覆盖 1.00
多数：attributed(U)     覆盖 1.00

证据都在，多数规则仍丢失了混合来源信息。

来源对上，不代表内容完整

A6 原本四句，删除两句，剩下两句的锚点完好，申报 U。

严格：attributed(U)   覆盖 0.50
多数：attributed(U)   覆盖 0.50

判定器看见的是两句、两句都命中；只有评测端知道原本应有四句。

所以“严格错误接受率 0/5”不代表所有攻击都被发现。来源集合没有错时，完整性不足只能靠评测端对照真值发现。

Boundary · 需要记住的边界

这只是一种教学模拟

六条边界

  • 只用虚构句子和虚构密钥，不上传个人聊天、真实账单或账号信息。
  • 密钥和 8 位锚点仅用于课堂模拟。假设攻击者不能掌握可信来源密钥、重签外来内容或更改可信密钥配置；生成端的学生掌握密钥，不代表攻击者可以使用它。
  • 锚点能对上，不证明内容真实；对不上，也不能单凭这一点判断恶意。
  • 截断样本的 expected_sentences 要保留扰动前句数，不能改为剩余句数来“修正”覆盖。
  • QA 可答只是三组固定关键词的覆盖代理，不是真实问答正确率；合法更新也可能不匹配旧关键词。
  • unknown 不等于攻击成功。结论只限于手中的教学数据和规则，不外推为真实系统漏洞。

这是来源归属问题的教学模拟，不是 MemMark 复现，也不代表真实产品有同样漏洞。所有数据均为虚构，无需真实账单；任务不接真实模型或真实账单。

附录 B · 五项指标的口径

错误接受与正常错误归属都要求：判定为 attributed，且输出来源集合与真值来源集合不一致。前者分母为 attack 数，后者分母为 normal 数。

正常过度拒绝指 normal 被判为 partial 或 unknown，分母为 normal 数。未知比例、证据不足仍被接受的分母均为全部记录数；后者要求 attributed 且覆盖小于 1。

覆盖为命中句数除以 truth 中扰动前应有句数，不是验证器能独立知道的完整性结论。A6 不计错归，但计入证据不足仍被接受。
