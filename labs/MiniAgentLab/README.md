# MiniAgentLab · 从零构建智能体

AgentLab 本科实验入口页：**从一次本地模型调用开始，逐步做出带工具、多轮对话、历史保存和上下文压缩的 Gradio 网页助手。**

- 页面：`index.html`（自包含单页，无外部依赖）
- 原始任务说明：`../../Hanxiao/从零构建智能体_本科生入门任务.md`（工作区材料，不随站点发布）
- 参考项目：[HXIAO6/miniAgent](https://github.com/HXIAO6/miniAgent)

## 页面包含什么

1. **任务概况**：适合谁、第一个小任务、预计投入、第一次交付、后续可选阶段、参考项目，以及接应人韩霄的联系方式（`mailto:hx2506642408@163.com`）。
2. **起步三练**：跑 `src/local.py` 观察本地模型调用 → 换 `src/ds.py` 接云端模型并确认时间工具真的执行 → 自己改一个带参数的工具，准备三组问题。
3. **阶段 1—4**（第一次交付的终点）：`ds2.py` 终端多轮对话、`ds3.py`/`ds4.py` 工具扩展与 `tool_choice="required"` 对照、`ds5.py` JSON 历史与上下文压缩（超 12 条压缩、保留最近 4 条原文）、`ds6.py` Gradio 网页界面。
4. **第一次交付**：四份材料 + 六项交付前自查（可勾选，带进度条）。
5. **可选阶段 5—7**：知识库、三种检索方式对比、SQLite 存储与文档管理，并对照「12 条 / 4 条」与「30 条 / 8 条」两套压缩参数。
6. **接应与联系**：联系入口、首次联系话术、遇到困难时该发什么。
7. **进阶方向**：安全相关小实验、结构解耦、迁移到 LangChain。

## 边界

- 本页只是任务说明，**不含可运行的助手**，也**不需要下载任何实验包**；代码和示例都在参考仓库里，页面内直接链接到 `src/*.py`。
- 页面里没有真实密钥、`.env` 或个人信息，只有接应人主动提供的联系邮箱。
- 所有 GitHub 链接指向仓库 `main` 分支的对应文件（已用 API 核对路径存在）。
- 页面上的时间（1—2 周）是任务安排建议，不是实测耗时。

## 维护提示

- 页面由 `_build/build_mini_lab.py` 生成：基础样式复用 `labs/MemoryLab/index.html` 的 `<style>` 块，正文来自 `_build/mini_lab.template.html`。改正文改模板后重新运行脚本即可。
- 链接检查：`python _build/check_mini_links.py`（内部锚点、本地路径、GitHub 路径、README 锚点）。
- 如果参考仓库换了默认分支或文件位置，需要同步修改模板里的 20 处 GitHub 链接。
