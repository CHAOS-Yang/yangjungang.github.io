01 / BUILD

Agent Builder

让 AI 使用工具、获取信息并完成实际任务。

可能的成果：智能应用、开源工具
02 / CODE

Coding Agent

探索 AI 如何理解代码、修复问题、测试和协助软件开发。

可能的成果：开发工具、系统评测
03 / COLLABORATE

Multi-Agent

研究多个智能体如何分工、协作、沟通并完成任务。

可能的成果：协作系统、算法实验
04 / PROTECT

Agent Security

当 AI 能调用工具和执行操作，怎样让它安全、可靠、可控？

可能的成果：安全测评、检测工具
05 / DISCOVER

Agent for Science

探索智能体怎样帮助科学研究、数据分析和真实系统。

可能的成果：科研工具、仿真原型
06 / INVENT

AI Innovation

YOUR STARTING ROUTE

先从 Explorer 开始

完成一个短小的 Agent 入门挑战，熟悉“任务—工具—反馈”的基本流程，再选择更适合你的路线。

  1. 第 1 周：了解 Agent 的基本结构
  2. 第 2 周：完成一个小型可运行 Demo
  3. 第 3 周：记录一次失败并尝试改进

这只是路线建议，不是选拔测试。你的选择只在当前浏览器中用于生成结果，不会被提交或保存。

How to join

先了解，再动手，然后一起匹配项目。

加入流程先关注学习和投入，不用绩点或论文经历给大一、大二同学设门槛。

了解 AgentLab

浏览方向和入门资料，想清楚自己喜欢什么、目前会什么。

完成入门挑战

选择一个 7–14 天的小任务，提交代码、实验记录或作品说明。

交流与匹配

根据兴趣、课程基础、时间投入和任务完成情况，一起选择起点。

加入项目迭代

从清晰的里程碑开始，持续记录、复盘和分享可复用成果。

Starter challenge · 7–14 days

选一个小挑战，做出可以展示的第一步。

不要求训练模型，也不要求购买 API。挑战重点是把任务做完、说明过程、讲清楚哪里有效和哪里失败。

BUILD CHALLENGE

做一个工具调用 Agent

让 Agent 使用一个简单工具完成一个明确任务。

  • 提交可运行代码和 README
  • 说明工具输入、输出和边界
RESEARCH CHALLENGE

复现一个小实验

读懂公开工作中的一个可验证结论，做一组对照实验。

  • 提交实验记录和结果图表
  • 写下一个失败案例或疑问
CREATIVE CHALLENGE

把创意变成 Demo

选一个学习、生活或专业场景，做一个最小可用原型。

  • 提交 Demo 或演示记录
  • 说明目标用户和下一步改进

Grow at your own pace

年级给建议，能力和兴趣决定从哪里做起。

学生可以在不同阶段进入或调整路线。一个大二同学可以直接做研究，一个大三同学也可以从基础工程任务开始。

L0 · Explorer

认识 Agent，完成挑战

建立概念，练习 Git 和基本开发环境，交付一个小作品。

L1 · Builder

独立完成一个项目

把工具、模型和环境连接起来，做出可复现的 Demo。

L2 · Researcher

复现、观察、提出问题

搭建基线，设计实验，依据证据判断一个方向是否值得继续。

L3 · Contributor

带着团队持续迭代

主导项目任务、维护公共工具，帮助下一位同学更快起步。

Questions students often ask

你可能还想知道。

我没有科研经历，可以申请吗？

可以。先从入门挑战开始，我们更关注持续投入、完成任务和主动复盘。

我必须会很多数学吗？

不需要。不同项目需要的基础不同，可以从编程、产品或实验任务开始。

刚加入就会分配论文 Idea 吗？

先通过小任务了解兴趣和基础，再一起匹配项目。未公开的研究问题会在内部讨论。

每周需要投入多少时间？

可以先从每周 2–4 小时开始。实际任务会根据你的学期安排协商确定。

准备好开始你的第一个小项目了吗？

来信时简单介绍年级、专业、学过的内容、感兴趣的方向和每周可投入时间即可。请勿发送身份证号等敏感信息。
