Explore the possibilities

可以探索哪些 Agent 方向？

这里介绍公开方向和项目类型。具体研究问题可以在交流、彼此了解之后再一起讨论；尚未公开的 Idea 不会放在网站上。

01 / BUILD

Agent Builder

让 AI 使用工具、获取信息并完成实际任务。

可能的成果：智能应用、开源工具
02 / CODE

Coding Agent

探索 AI 如何理解代码、修复问题、测试和协助软件开发。

可能的成果：开发工具、系统评测
03 / COLLABORATE

Multi-Agent

研究多个智能体如何分工、协作、沟通并完成任务。

可能的成果：协作系统、算法实验
04 / PROTECT

Agent Security

当 AI 能调用工具和执行操作，怎样让它安全、可靠、可控？

可能的成果：安全测评、检测工具
05 / DISCOVER

Agent for Science

探索智能体怎样帮助科学研究、数据分析和真实系统。

可能的成果：科研工具、仿真原型
06 / INVENT

AI Innovation

把感兴趣的问题变成可体验、可验证的 Agent 创意。

可能的成果：竞赛作品、大创项目

Grow at your own pace

年级给建议，能力和兴趣决定从哪里做起。

学生可以在不同阶段进入或调整路线。一个大二同学可以直接做研究，一个大三同学也可以从基础工程任务开始。

L0 · Explorer

认识 Agent，试试小练习

从网页体验、流程图或简单原型里，挑一个合适的起点。

L1 · Builder

独立完成一个项目

把工具、模型和环境连接起来，做出可复现的 Demo。

L2 · Researcher

复现、观察、提出问题

搭建基线，设计实验，依据证据判断一个方向是否值得继续。

L3 · Contributor

参与共建，支持新同学

有余力时维护工具或分享经验，让后来者更容易起步。

Questions students often ask

你可能还想知道。

我没有科研经历，可以来聊聊吗？

当然可以。不需要先做完挑战或准备简历；从你感兴趣的问题开始就好。

数学基础不强，也可以开始了解吗？

当然可以。不同方向用到的知识不一样，遇到需要的部分再慢慢补也可以。

刚开始还没有明确方向，怎么办？

很正常。可以先试玩小 Demo，也可以直接来信；我们再根据你的兴趣和基础一起找一个合适的起点。

我还不确定能投入多少时间，怎么办？

可以先说说这学期的课程安排，我们再一起商量合适的节奏。

想了解更多？欢迎随时来信。

几句话介绍自己和好奇的方向就可以；还没想好做什么、也还没有 Demo，都没关系。无需准备简历或成绩单，请不要发送身份证号等敏感信息。
